Nothing here touches PayPal. This page runs the real gateway code (countersign@482db35) in your browser, against the fake PayPal from tests/fakes.py. Its refund ids are not PayPal ids. The state is in this tab only and starts over when you reload.

Starting the gateway in your browser. The first visit takes a few seconds.
  1. Load Python (Pyodide) with pydantic and httpx
  2. Install openscript-sdk 0.1.0
  3. Start the gateway and replay seven agent requests

Waiting for a person 0 operator token

A refund above the auto-limit is held and nothing is sent. Approving runs that exact refund with the stored arguments. Every figure on a card is from PayPal or the gateway; none of it is text the customer or the model wrote.

Ask as the agent agent token

No model runs here; you play the agent. It can ask for a refund. It cannot open a ticket, approve, or call PayPal.
